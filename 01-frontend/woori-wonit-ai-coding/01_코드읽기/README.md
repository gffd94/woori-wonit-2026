화면에 우리WON뱅킹 계좌 목록과 거래내역이 정상적으로 보이면 준비 완료입니다.

## 미션

1. `f3` 함수가 정확히 무슨 일을 하는지 AI에게 설명해 달라고 요청해 보세요.
2. `f1`, `f2`, `f3`, `f4`와 그 안의 변수들(`a`, `b`, `x`, `y`, `d`, `arr2`, `tmp` 등) 이름을 의미가 드러나도록 AI에게 바꿔 달라고 해 보세요.
3. 각 함수 위에 그 함수가 하는 일을 설명하는 주석을 달아 달라고 해 보세요.
4. `f1` 함수가 제대로 동작하는지 확인할 수 있는 테스트 코드를 AI에게 만들어 달라고 해 보세요.

AI가 준 설명이 맞는지 직접 실행해서 확인하세요.
