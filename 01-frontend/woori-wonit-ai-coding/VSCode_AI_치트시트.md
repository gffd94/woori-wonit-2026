# VS Code + AI 치트시트

> 한 장으로 끝내는 요약본입니다. **출력해서 옆에 두고 쓰세요.**
> 단축키와 메뉴는 VS Code 버전에 따라 조금 다를 수 있습니다. 안 되면 `Ctrl+Shift+P` 로 명령을 검색하세요.

---

## 1. AI를 부르는 네 가지 방법

| 방법 | 단축키 | 언제 쓰나 |
|---|---|---|
| **자동완성** | (그냥 타이핑) `Tab` 수락 · `Esc` 거절 | 짧은 코드, 반복되는 코드 |
| **인라인 채팅** | `Ctrl + I` | **코드를 선택해두고** 그 자리에서 고칠 때 |
| **채팅 패널** | `Ctrl + Alt + I` | 길게 물어볼 때, 여러 번 주고받을 때 |
| **빠른 채팅** | `Ctrl + Shift + Alt + L` | 하던 일 안 끊고 한 번만 물을 때 |

<br>

**가장 많이 쓰게 될 흐름은 이겁니다.**

```
코드를 드래그해서 선택  →  Ctrl + I  →  질문 입력  →  Enter
```

---

## 2. 자주 쓰는 슬래시 명령

채팅창에 `/` 를 치면 나옵니다. **코드를 먼저 선택**하고 쓰면 훨씬 정확합니다.

| 명령 | 하는 일 |
|---|---|
| `/explain` | 이 코드가 무슨 일을 하는지 설명 |
| `/fix` | 문제를 찾아 고쳐줌 |
| `/tests` | 테스트 코드 생성 |
| `/doc` | 주석·문서 달아줌 |
| `/clear` | 대화 초기화 (**엉뚱한 답이 계속 나올 때 이걸 먼저**) |

---

## 3. 문맥을 붙이는 법

AI는 **내가 보여준 것만** 압니다. 화면에 열려 있어도 모를 수 있습니다.

| 쓰는 법 | 뜻 |
|---|---|
| `#selection` | 지금 선택한 코드 |
| 파일을 채팅창에 **드래그** | 그 파일 전체를 문맥으로 |
| `@terminal` | 터미널에서 난 에러에 대해 물을 때 |
| `@vscode` | VS Code 기능 자체가 궁금할 때 |

## 4. 프롬프트 템플릿 3개

### ① 코드를 이해하고 싶을 때

```
이 코드가 무슨 일을 하는지 비전공자가 알아듣게 설명해줘.
- 한 줄씩 말고, 전체 흐름을 3~4문장으로 먼저
- 어려운 용어가 나오면 괄호 안에 쉬운 말로
- 마지막에 "이 코드를 한 문장으로" 요약
```

### ② 고쳐달라고 할 때

```
아래 코드를 고쳐줘.
- 고친 코드를 주기 전에, 무엇이 왜 잘못됐는지 먼저 2~3줄로 설명해줘
- 전체를 새로 쓰지 말고, 바꿔야 하는 부분만 알려줘
- 확실하지 않으면 "확실하지 않다"고 말하고, 뭘 확인해야 하는지 알려줘
```

### ③ 새로 만들어달라고 할 때

```
[무엇을] 만들어줘.
- 순수 HTML/CSS/JS로만. 라이브러리 쓰지 말고
- 금액은 원 단위 정수로 다뤄줘
- 코드에 한글 주석을 달아줘
```

## 5. 디버깅할 때 반드시 챙길 세 가지

> **"안 돼요"는 프롬프트가 아닙니다.**

| | 예시 |
|---|---|
| **재현 조건** | "입금 버튼을 누르면" |
| **기대 동작** | "잔액이 1만원 올라가야 하는데" |
| **실제 동작** | "아무 일도 안 일어납니다. 콘솔에는 에러가 없습니다" |

여기에 **에러 메시지를 통째로** 붙입니다. 요약하지 마세요.

```
TypeError: Cannot set properties of null (setting 'textContent')
    at renderBalance (app.js:52:41)
    at app.js:78:1
```

<br>

**한 줄 요약 프롬프트**

```
입금 버튼을 눌렀을 때 잔액이 올라가야 하는데 아무 반응이 없습니다.
콘솔 에러는 없습니다. 아래는 관련 코드와 HTML입니다.
왜 이런지 먼저 설명해주고, 그 다음에 고친 코드를 주세요.
```

## 6. CSS를 물어볼 때는 다르게 묻습니다

**CSS는 에러가 나지 않습니다.** 그래서 AI는 뭐가 문제인지 알 수가 없습니다.
"안 예뻐요" 대신 **보이는 그대로**를 말하세요.

```
모달이 화면에 안 보입니다.
JS로 display를 block으로 바꾸는 건 개발자도구에서 확인했는데,
화면에는 회색 배경만 보이고 모달 박스가 안 보입니다.
아래가 관련 CSS입니다.
```

## 8. AI가 자주 틀리는 지점

| 상황 | AI가 흔히 하는 답 | 실제 정답 |
|---|---|---|
| 금액에 소수점이 붙음 | `toFixed(2)` 를 쓰라고 함 | **틀렸습니다.** 문자열이 되고 소수점도 남습니다. 금액은 `Math.round()` 로 **원 단위 정수** |
| 에러 한 줄만 보여줌 | 그럴듯한 추측을 함 | 스택트레이스 **전체**를 줘야 정확해집니다 |
| 코드가 길어짐 | 파일 전체를 새로 써줌 | "바뀐 부분만" 이라고 못 박으세요 |
| 같은 실수 반복 | 계속 같은 답 | `/clear` 로 대화를 지우고 다시 물으세요 |

---

## 9. 막혔을 때 순서

1. **에러 메시지를 읽는다** — 파일명과 줄 번호가 적혀 있습니다
2. 그 줄로 가서 **눈으로 한 번 본다**
3. 안 보이면 **코드를 선택하고 `Ctrl+I`**
4. AI 답이 이상하면 **`/clear` 후 재현 조건·기대·실제 3종 세트로 다시**
5. 그래도 안 되면 **강사를 부른다** (이게 제일 빠를 때도 많습니다)
