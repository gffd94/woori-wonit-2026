# 4교시 실습 — AI로 디버깅하기

VS Code에서 이 폴더를 열고 `index.html`을 우클릭 → **Open with Live Server** 를 누르세요.
화면을 열어 아래 증상들을 직접 확인한 뒤, AI에게 물어보며 하나씩 고쳐 보세요.

## 증상 (다섯 가지)

1. 잔액이 화면에 안 나옵니다.
2. 입금 버튼을 눌러도 아무 일이 없습니다.
3. 이자를 더하면 잔액에 이상한 소수점이 붙습니다.
4. 환율 자리에 `[object Promise]` 라고 뜹니다.
5. 이체 확인 버튼을 눌러도 창이 안 보입니다.

## AI에게 물어볼 때 챙길 3가지

버그를 발견하면 아래 세 가지를 반드시 포함해서 AI에게 질문하세요.

1. **재현 조건** — 무엇을 했을 때 이 문제가 생기나요? (어떤 버튼을 눌렀는지, 어떤 화면인지)
2. **기대 동작** — 원래 어떻게 동작해야 하나요?
3. **실제 동작** — 실제로는 어떻게 됐나요? (개발자 도구 콘솔에 에러가 떴다면 **에러 메시지 전문**을 그대로 복사해서 붙여넣으세요)

AI가 준 답을 붙여넣기 전에, 왜 그런지 한 문장으로 설명할 수 있어야 합니다.
